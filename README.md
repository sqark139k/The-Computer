# THE COMPUTER — รุ่น 2.0

เครื่องคิดเลขสไตล์เรโทร พร้อมตัวละครคอมพิวเตอร์พิกเซลที่มีบุคลิกเป็นของตัวเอง

## วิธีเปิดใช้งาน
แตกไฟล์ ZIP แล้วเปิด `index.html` ด้วยเว็บเบราว์เซอร์

## ความสามารถ
**เครื่องคิดเลข**
- บวก ลบ คูณ หาร ยกกำลัง เปอร์เซ็นต์ ทศนิยม และสลับเครื่องหมาย รองรับแป้นพิมพ์
- ต่อจากคำตอบเดิมได้ทันที กด `=` ซ้ำเพื่อทำการคำนวณล่าสุดซ้ำ
- อ่านตัวเลขบนจอเป็นภาษาไทยให้ใต้จอ
- หน่วยความจำ M+, M−, MR, MC และคัดลอกผลลัพธ์

**เครื่องมือเสริม**
- วิทยาศาสตร์: √ ∛ x² x³ xʸ 1/x |x| n! sin cos tan (DEG/RAD) log ln eˣ 10ˣ π e สุ่ม
- แปลงหน่วย: สกุลเงิน (แก้อัตราได้) พื้นที่ไทย (ไร่ งาน ตารางวา) ความยาว (วา เส้น) น้ำหนัก (บาททองคำ) อุณหภูมิ
- เงิน: คิด VAT ทั้งแบบบวกและถอด และหารบิลร้านอาหารพร้อมค่าบริการ
- อ่านเลข: ตัวเลขไทย และจำนวนเงินแบบ "...บาทถ้วน"

**ตัวละคร**
- ทักทายตามช่วงเวลา และบ่นเมื่อคิดเลขดึก
- ถ้าปล่อยทิ้งไว้ 30 วินาทีจะเบื่อ แล้วหลับพร้อมตัว Z ลอย คลิกหรือกดปุ่มเพื่อปลุก
- ตกใจเมื่อหารด้วยศูนย์ เหนื่อยเมื่อเจอเลขใหญ่หรือต่อลูกโซ่ยาวๆ
- เสียงพูดแบบบี๊บ โทนเปลี่ยนตามอารมณ์

**เกมและของสะสม**
- เกมท้าทายคิดเลขเร็ว 10 ข้อ จับเวลา เก็บสถิติสูงสุดในเครื่อง
- ผลงาน 24 แบดจ์
- ประวัติแสดงเป็นม้วนใบเสร็จ พิมพ์ทีละบรรทัด และบันทึกเป็นรูป PNG ได้

**ตั้งค่า**
- เส้นสแกน แสงหน้าจอ บทสนทนา เสียงพูด การหลับ การอ่านเลขใต้จอ และเสียงคลิก
- การตั้งค่า ผลงาน สถิติเกม และอัตราแลกเปลี่ยนถูกจำไว้ในเบราว์เซอร์

## หมายเหตุ
- เสียงทั้งหมดสร้างจาก Web Audio API ไม่ต้องดาวน์โหลดไฟล์เสียง บางเบราว์เซอร์ต้องให้คลิกหน้าเว็บก่อนจึงจะเล่นเสียงได้
- อัตราแลกเปลี่ยนที่ให้มาเป็นค่าตัวอย่าง ไม่ใช่อัตราจริง ควรแก้ให้ตรงกับวันที่ใช้งาน
